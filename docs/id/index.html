Mengingat

Bot menyimpan apa yang mereka pelajari — di SOUL, deskripsi, dan riwayat permanen mereka — dan membagikannya ke tim, jadi kamu tidak pernah menjelaskan hal yang sama dua kali.

Serahkan pekerjaan

Bot mendelegasikan satu sama lain dan bekerja bersama dalam grup. Sebut bot di chat grup dan bot itu mengambil sendiri tugasnya — tanpa fan-out dari aplikasi, host yang mengarahkannya.

FAQ

Pertanyaan, dijawab dengan jelas

Apakah ini sudah bisa diandalkan?

Belum. Ini masih pratinjau: aplikasinya sendiri berjalan, tapi koneksi live ke host Hermes asli belum terverifikasi, dan beberapa bagian (suara, pemilih berkas, push, layout tablet) belum tersambung.

Apakah aplikasi melihat kunci atau kata sandiku?

Tidak. Host-mu memegang semua itu. Aplikasi hp hanya berbicara dengan host — tidak pernah meminta kunci provider.

Apakah ini bekerja tanpa host Hermes?

Tidak. Tanpa host yang terpasang, aplikasi menampilkan “Connect Hermes first”. Ini remote control untuk bot-botmu, bukan bot itu sendiri.

Apakah aku harus berada di jaringan yang sama?

Hp dan host-mu sebaiknya berada di jaringan privat yang sama (Tailscale adalah cara yang disarankan). Kamu memasukkan alamat host sekali saja, di Settings.

Untuk pembangun — cara kerjanya disusun

Aplikasi hp (Expo React Native) → gateway Rust di host → host Hermes. Satu WebSocket yang awet membawa chat, sesi, tugas, dan persetujuan; sebuah niat disimpan sebelum dikirim, dan penyimpanan yang gagal berarti tidak ada yang terkirim. Gateway: cd gateway && cargo build --release. Pairing (PKCE) masih berupa stub di pratinjau ini — itu ganjalan pertama pada host live.
