Turn journaling, not fire-and-forget

An intent is persisted before it is sent. A failed write sends nothing, and a session held elsewhere shows as read-only instead of silently conflicting.

One durable connection

Chat, sessions, tasks and approvals ride one WebSocket (/api/ws, JSON-RPC) to the gateway — no polling, no duplicated state.

Group chats, attributed

Several bots in one conversation, each reply attributed to its sender. That is the app's version of peer-bot delegation.

Your host, your control

Your machine, your bots, your limits.

Hermes Bots is a remote control surface, not an agent runtime. It runs no model, holds no provider credentials, and executes no tools. The Hermes host remains the sole authority.

Your host's model

Each bot uses the model its host is configured with. The app never picks a provider for you and never sees the key.

Work on a schedule

Recurring tasks run on the host while it stays on — the phone only checks in and reviews results.

You set the limits

Decide which actions need your approval. Nothing sensitive runs while you are not looking.

Get connected

  1. Run the Rust gateway on your Hermes host: cd gateway && cargo build --release
  2. Put your phone and host on the same Tailscale tailnet.
  3. In the app, go to Settings → Connection and enter the gateway's tailnet address — never 127.0.0.1 on the phone.
  4. Probe /api/status and pair. PKCE pairing is still a stub in this preview — expect that step to be the first rough edge.

FAQ

Frequently asked questions

Is this production-ready?

No. It is a preview. The core client is implemented and the Android build is green, but a live Hermes host connection has not been verified yet, pairing is a stub, and voice, file picker, push and the tablet layout are not wired.

Does the app hold my provider credentials?

No. The host holds the model, credentials and history. Provider credentials never enter the app, and tokens live only in SecureStore.

Do I need a Hermes host?

Yes. Without a paired host the app shows “Connect Hermes first”. This is a control surface, not a standalone agent.

Do I need Tailscale?

It is the recommended path: phone and host on the same tailnet, then enter the gateway's tailnet address in Settings → Connection. The gateway listens on the host only by default.

Why is the APK ~240 MB?

It is a universal debug build with 4 ABIs, not a stripped release build. That size is a preview-build property, not the app's real footprint goal.
