FAQ

Questions, answered plainly

Is this ready to rely on?

Not yet. It is a preview: the app itself works, but a live connection to a real Hermes host has not been verified, and a few pieces (voice, file picking, push, tablet layout) are not wired yet.

Does the app see my keys or passwords?

No. Your host holds all of that. The phone app only talks to the host — it never asks for a provider key.

Does it work without a Hermes host?

No. Without a paired host it shows “Connect Hermes first”. This is a remote control for your bots, not a bot by itself.

Do I need to be on the same network?

Your phone and host should be on the same private network (Tailscale is the recommended way). You enter the host's address once, in Settings.

For builders — how it is put together

Phone app (Expo React Native) → Rust gateway on the host → Hermes host. One durable WebSocket carries chat, sessions, tasks and approvals; an intent is saved before it is sent, and a failed save sends nothing. Gateway: cd gateway && cargo build --release. Pairing (PKCE) is still a stub in this preview — that is the first rough edge on a live host.
