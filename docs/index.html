What it does

Everything a control surface needs — and nothing it should not do.

Live chat

Streamed bot replies over a single durable WebSocket, with turn journaling: an intent is persisted before it is sent, and a failed write sends nothing.

Sessions

The full runtime session projection, including read-only sessions held elsewhere.

Tasks

Scheduled and recurring bot work, with pause, resume, trigger and delete.

Approvals & clarifications

Review bot questions and sensitive actions before they run.

Computer view

Read-only host display thumbnail. Take-control is not implemented yet.

Private by design

Provider credentials never enter the app. Tokens live only in SecureStore, and cleartext stays off by default.

How it works

Hermes Bots is a remote control surface, not an agent runtime. It runs no model, holds no provider credentials, and executes no tools.

  1. Run the Rust gateway on your Hermes host: cd gateway && cargo build --release
  2. Put your phone and host on the same Tailscale tailnet.
  3. In the app, go to Settings → Connection and enter the gateway's tailnet address — never 127.0.0.1 on the phone.
  4. Probe /api/status and pair. The host remains the sole authority for agents, credentials, approvals, tools, sessions, files and history.
